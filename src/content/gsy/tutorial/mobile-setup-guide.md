## 01. 移动端流媒体专线部署核心原则与网络架构

移动智能手机（无论是苹果 iPhone 还是安卓各品牌旗舰）是当代用户观看 9:16 竖屏短剧最主要、最频繁的终端载体。然而，移动网络环境的复杂程度远远超过固定宽带——手机需要在 5G 基站移动漫游、公共 Wi-Fi、家庭 Wi-Fi 之间高频切换，且必须严格兼顾**电池续航功耗、国内常用 App 兼容性（微信/支付宝/网银）以及海外短剧 4K 秒开性能**。

```
[Mobile Device System Network Stack Architecture]
+-------------------------------------------------------------+
| Foreground User Action: YellowFruit ShortPlay (Port 443)    |
| Background Apps: WeChat, Alipay, System Cloud Sync          |
+-------------------------------------------------------------+
                            │
       (Virtual Interface: VpnService / NetworkExtension)
                            │
                            ▼
+-------------------------------------------------------------+
| Local Proxy Engine: Shadowrocket (iOS) / Clash Meta (Android)|
+-------------------------------------------------------------+
| Rule Matching Engine (Domain-Keyword / GeoIP / CIDR):       |
| 1. Domestic Domains (WeChat, Taobao, CN IPs) ──> DIRECT     |
| 2. Short Drama & Overseas Media Streams       ──> PROXY      |
+-------------------------------------------------------------+
       │                                         │
  [DIRECT Traffic Path]                     [PROXY Traffic Path]
       │                                         │
       ▼                                         ▼
+-----------------------------+           +-----------------------------+
| Local Telecom/Mobile 5G     |           | GuangSu Cloud IEPL Tunnel   |
| Normal Domestic Speed       |           | 18ms Latency to Hong Kong   |
| Zero Extra Battery Drain    |           | 2.5Gbps Chunk Pre-loading   |
+-----------------------------+           +-----------------------------+
```

在手机端配置商业网络专线，必须坚决遵循三大核心技术原则：
1. **严格坚持规则分流（Rule-Based Routing），坚决杜绝全局代理（Global Proxy）**：短剧流量自动走专线，国内流量走本地直连，免除频繁手动开关，避免国内 App 误报异地风险；
2. **保障移动基带低功耗唤醒**：合理配置客户端的分流规则与本地 DNS 缓存，避免后台出现死循环轮询导致手机机身发烫、电量雪崩；
3. **防止 DNS 泄露与 GeoIP 污染**：通过专线内部的加密 DoH/DoT 通道拉取流媒体切片，彻底消灭运营商本地拦截。

本文将为您提供 iOS（以 Shadowrocket 小火箭为主）与 Android（以 Clash Meta 为主）的保姆级深度实操手册。

## 02. 苹果 iOS 深度配置指南 (Shadowrocket 小火箭)

在苹果生态中，**Shadowrocket（俗称小火箭）** 是公认性能最成熟、资源占用最低、协议支持最全面的代理工具。

### 步骤一：在光速云后台一键获取托管订阅链接
1. 打开 iPhone 自带的 Safari 浏览器，访问 [光速云官方网站（guangsucloud.com）](https://guangsucloud.com) 并登录用户中心；
2. 在控制台首页的“便捷导入”区域，找到并点击 **“一键导入 Shadowrocket”**；
3. 如果系统弹出提示“是否在‘Shadowrocket’中打开”，点击允许即可一键全自动导入；
4. 若选择手动复制：点击 **“复制通用订阅链接”**，系统会自动将加密 Token 存入剪贴板。

### 步骤二：Shadowrocket 手动添加与节点同步
如果您使用的是手动复制链接：
1. 打开 Shadowrocket 应用，进入主界面；
2. 点击屏幕右上角的 **“+”** 加号图标进入添加节点页面；
3. 点击第一项“类型（Type）”，在下拉列表中向上滑动选择 **“Subscribe（订阅）”**；
4. 在 **“URL”** 输入框中，长按并粘贴刚才在光速云后台复制的专属订阅链接；
5. 在下方“备注（Remarks）”栏中输入“光速云 IEPL 专线”；
6. 点击右上角的 **“完成（Save）”**；
7. 软件会立即向光速云订阅服务器发起一次加密握手，并在 2 秒内拉取包含中国香港、中国台湾、新加坡、日本等全部 11 国的高性能专线节点列表。

### 步骤三：路由模式与节点优选设定（至关重要）
很多新手用户在此处踩坑，导致手机耗电剧增：
1. **检查“全局路由（Global Routing）”模式**：
   - 必须确保主界面中间的“全局路由”选项处于 **“配置（Config）”** 状态！
   - **绝对不要选择“代理（Proxy）”**（代理模式会把国内微信、抖音全部强行代理，白白浪费专线流量且导致网银报警）；
2. **选择适合短剧的低延迟节点**：
   - 在下方展开的节点列表中，轻点选中 **“🇭🇰 香港 01 [IEPL专线]”** 或 **“🇹🇼 台湾 01 [原生专线]”**（节点前出现橙色或黄色圆点即代表选中）；
3. **滑动开关启动服务**：
   - 将最顶部的“未连接”开关向右滑动开启；
   - 首次启动时，iOS 系统会弹出“‘Shadowrocket’想添加 VPN 配置”的安全对话框，点击 **“允许（Allow）”** 并输入 iPhone 锁屏密码或通过 Face ID 验证。
4. 顶部状态栏出现“VPN”小方框图标，表明专线已正式投入运行！

## 03. 安卓 Android 深度配置指南 (Clash Meta / Flclash)

在安卓生态中，推荐采用基于开源 Meta 内核的 **Clash Meta for Android（CMFA）** 或界面优雅的 **Flclash**，兼具强悍的性能与极简的交互。

### 步骤一：获取 Android 专属订阅链接并导入配置
1. 手机浏览器登录光速云官网后台，点击“一键导入” -> **“复制 Clash 订阅链接”**；
2. 打开 Clash Meta 应用，在主界面点击底部的 **“配置（Profiles）”**；
3. 点击屏幕右上角的 **“+”** 加号；
4. 选择第二项 **“URL（从 URL 导入）”**；
5. 在“名称”中填写“光速云专线”；在“URL”中长按粘贴刚才复制的订阅链接；
6. 在“自动更新（Auto Update）”中，建议设置为 **`1440 分钟（即 24 小时）`**，让客户端每天在后台静默同步最新节点状态；
7. 点击右上角的“保存（磁盘图标）”，软件自动下载并校验 YAML 配置文件，勾选将其设为当前活动配置。

### 步骤二：开启规则分流与亚太专线优选
1. 返回应用主页，点击进入 **“代理（Proxy）”** 策略组管理页面；
2. 确保最上方的运行模式选择为 **“规则模式（Rule）”**；
3. 在策略组中找到“🎬 短剧/流媒体”或默认的“GLOBAL / PROXY”分组：
   - 点击右上角的闪电测速图标进行并发测速；
   - 挑选延迟数值最低（通常在 15ms - 35ms 之间）的 **“香港 IEPL”** 或 **“台湾原生”** 节点；
4. 返回主页，点击中央的 **“已停止（点击启动）”** 大按钮；
5. 在安卓系统弹出的“网络连接请求”对话框中点击 **“确定”**。通知栏显示钥匙小图标即代表加速成功。

## 04. 移动端高频报错诊断与自救排查 SOP

在手机移动端使用过程中，如果遇到突发异常，请按照以下速查手册进行精准排障：

```
[Mobile Troubleshooting Decision Matrix]
==================================================================================
症状 1: 开启后国内微信无法刷新/图片转圈 ──> 100% 模式误设为“全局”，切换回“配置/规则”
症状 2: 节点列表全红显示 Timeout/超时   ──> 检查手机系统时间是否开启“自动校准”
症状 3: Wi-Fi 换 5G 后突然卡住不动     ──> 在客户端中开启“自动重连 / 唤醒检测”
症状 4: 手机机身发热发烫、电池狂掉       ──> 关闭应用内日志级别 (LogLevel = Silent)
==================================================================================
```

### 故障一：开启代理后微信、淘宝无法刷新或提示网络异常
- **根因分析**：路由模式被误触切换为了“全局代理（Global / Proxy）”，或者本地分流规则文件损坏；
- **解决动作**：
  1. 打开客户端，将运行模式从“全局”切回 **“规则（Rule）/ 配置（Config）”**；
  2. 若依然异常，在 Shadowrocket 底部的“配置”页面中，点击右上角加号重新下载官方默认规则（如 `https://raw.githubusercontent.com/...`）。

### 故障二：所有节点测速均显示“Timeout”或“连接超时”
- **根因分析**：
  1. 本地手机时钟偏差超过 60 秒，导致 TLS 加密验签失败；
  2. 订阅链接过期或流量已耗尽；
- **解决动作**：
  1. 打开手机【设置】->【通用】->【日期与时间】，务必开启 **“自动设置”**；
  2. 登录光速云后台检查套餐流量是否充足；
  3. 在客户端中向下滑动刷新订阅，拉取最新节点配置。

### 故障三：从家庭 Wi-Fi 走到室外切换为 5G 移动蜂窝后断网
- **根因分析**：操作系统的底层网络物理接口发生跳变，客户端的虚拟 Socket 套接字未能及时感知并挂起；
- **解决动作**：
  - 在 Shadowrocket 设置中，进入“TCP”栏目，开启 **“断网自动重连（Auto Reconnect）”**；
  - 遇到断网时，下拉控制中心开启“飞行模式” 5 秒后再关闭，即可强制重新建立 PDP 上下文通道。

## 06. 常见移动端配置 FAQ 问答库

### Q1: 苹果手机的 Shadowrocket（小火箭）需要单独购买吗？
**答**：Shadowrocket 是 iOS 平台上由第三方开发者独立开发的买断制收费软件（美区 App Store 售价约 2.99 美元）。若您的 Apple ID 尚未购买该软件，光速云官方用户后台通常提供便捷的下载辅助方案或合租账号支持，您也可以直接查阅官网控制台右下角的实时在线客服获取协助。

### Q2: 手机开启加速后，可以给电脑开热点共享看短剧吗？
**答**：可以。在安卓端（Clash Meta）中，进入设置勾选 **“允许局域网连接（Allow LAN）”**；在苹果端（Shadowrocket）中开启“共享代理”，电脑连接手机热点后在电脑网络设置中填写对应的局域网 IP 与端口即可全家共享专线网络。

### Q3: 为什么看短剧时有时提示“DNS 无法解析”？
**答**：这通常是因为手机缓存了旧的 DNS 解析记录。请在 Shadowrocket 主界面点击“DNS”，选择清空 DNS 缓存；或者直接在光速云客户端中启用 DoH（DNS over HTTPS）加密解析功能，即可彻底免疫本地电信/移动的 DNS 污染拦截。

### Q4: 购买了光速云后，一部手机配置好，换新手机需要重新买吗？
**答**：完全不需要。光速云全系列套餐均**不限制设备同时在线连接**。您在新手机上下载对应的客户端，再次导入您的专属订阅链接即可立即使用，甚至两部手机同时在线刷剧也互不干扰。
