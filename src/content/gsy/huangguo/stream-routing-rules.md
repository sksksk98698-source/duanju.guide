## 01. 智能分流 (Rule-Based Routing) 核心机理与流量精算

在许多初级网络专线使用者的认知中，常常存在一个极其普遍的操作误区：“只要打开软件，直接选‘全局模式（Global Proxy）’就完事了，反正能上网就行”。

然而在真实的长期使用中，“全局代理”会引发一系列极其严重的负面连锁反应：
1. **专线流量瞬间被偷跑吞噬**：国内的微信视频通话、抖音刷短视频、网易云音乐听歌、乃至手机后台的 iCloud/相册同步，全部被迫经过境外专线绕行一圈，导致原本足够看几个月短剧的 120GB 流量在短短三四天内被榨干；
2. **国内正常业务访问发生严重的“逆向高延迟”**：本来在本地城域网仅需 5ms 即可打开的国内网页，被迫绕行香港或新加坡再折返回来，延迟暴增 10 倍以上；
3. **高频触发银行与支付风控报警**：支付宝、微信支付、手机银行检测到用户 IP 突然从大陆跳跃至香港机房，会强制要求短信二次验证甚至直接锁定账户；
4. **手机机身持续发热发烫**：基带芯片与代理内核对所有后台数据报进行高频加解密计算，严重损耗电池寿命。

```

Inbound User Traffic (Port 80 / 443 / DNS 53)
  │
  ├───> [Deep Packet Domain & IP Inspection Engine]
  │         │
  │         ├── Target: 国内微信 / 淘宝 / 百度 / GEOIP, CN
  │         │     │
  │         │     └───> [DIRECT Action] ──> 本地电信/移动宽带直连 (0 流量损耗, 0 延迟放大)
  │         │
  │         └── Target: 黄果短剧 / 跨国 HLS 切片 (.m3u8, .m4s) / 海外 CDN
  │               │

==================================================================================
```

## 02. 短剧全链路分流域名特征库深度剖析

短剧网站与现代移动 App 绝非运行在单一服务器上，而是由极其庞杂的分布式微服务矩阵构成。要实现精准分流，必须精准识别以下四大维度的网络流量特征：

### 1. 核心 API 网关与鉴权接口
- 负责用户登录态验证、会员等级校验、剧集解锁计费与推荐算法列表拉取；
- 常见特征关键词：`api.huangguo.com`、`gateway.*.shortdrama.*`、`auth.*`。
- **路由动作**：**必须走 PROXY 专线**（确保海外安全网关能够识别为高纯净度原生 IP，杜绝 403 地区阻断）。

### 2. HLS / DASH 音视频流媒体分片 CDN 集群
- 承载体积巨大的视频切片（`.m3u8` 索引清单与 `.ts` / `.m4s` 媒体载荷）；
- 核心分发网络主要依托全球顶级边缘 CDN，如 AWS CloudFront（`*.cloudfront.net`）、Cloudflare Enterprise（`*.cloudflare.com`、`*.cf-ipfs.com`）与 Fastly；
- **路由动作**：**必须走 PROXY 专线**（依托光速云单节点 2.5Gbps 超大管道与 0 丢包特性，瞬间拉满播放器前向缓冲区）。

### 3. 静态前端资源与剧集海报图片墙
- 存放数以万计的剧照、演员肖像、UI 样式与 JavaScript 脚本；
- **路由动作**：**建议走 PROXY 专线**（确保首屏海报图片墙在 0.3 秒内瞬间平铺全屏，消除“挤牙膏式”逐行加载）。

### 4. 国内基础民生服务白名单
- 包含微信（`wechat.com`、`qq.com`）、支付宝（`alipay.com`）、淘宝、京东、各大银行、国内主流短视频（抖音、快手、Bilibili）；
- **路由动作**：**必须强制锁定 DIRECT 直连**（不消耗专线流量，杜绝任何异地登录风险）。

## 03. Clash / Clash Verge 生产级 YAML 分流规则配置实战

对于在 Windows、Mac 或安卓手机上使用 Clash Verge Rev、Clash Nyanpasu、Clash Meta 的用户，可以直接将以下生产级专业分流策略嵌入到客户端的“配置扩展（Merge / Script）”或自定义规则中：

```yaml

  # 专属策略组 1: 短剧与海外流媒体
  - name: 🎬 黄果短剧-智能专线
    type: select
    proxies:
      - 🇭🇰 香港 01 [IEPL专线]
      - 🇭🇰 香港 02 [IEPL专线]
      - 🇹🇼 台湾 01 [原生专线]
      - 🇸🇬 新加坡 01 [IEPL专线]

  # 专属策略组 2: 自动容灾优选 (每 5 分钟自动检测延迟最低节点)
  - name: ⚡ 自动优选专线
    type: url-test

  - DOMAIN-SUFFIX,duanju.guide,DIRECT
```

## 04. 苹果小火箭 (Shadowrocket) 深度规则编写实战

对于在 iPhone 或 iPad 上使用 Shadowrocket 的用户，配置自定义短剧分流规则仅需 1 分钟：

```
[Shadowrocket 手动添加短剧规则实操路径]
1. 点击底部导航栏的【配置 (Config)】标签页；
2. 在“本地配置”列表中，轻点当前正在使用的规则配置文件（如 default.conf），选择【编辑规则 (Edit Rules)】；
3. 点击右上角【+】加号图标，依次添加两条关键规则：
   - 第一条:
     * 类型 (Type): DOMAIN-KEYWORD
     * 数值 (Value): huangguo
     * 策略 (Policy): PROXY
   - 第二条:
     * 类型 (Type): DOMAIN-SUFFIX
     * 数值 (Value): cloudfront.net
     * 策略 (Policy): PROXY
4. 点击保存后，回到 Shadowrocket 主界面；
5. 检查中间的【全局路由 (Global Routing)】，必须保持在【配置 (Config)】状态！
```

## 06. 常见分流配置 FAQ 问答库

### Q1: 配置完分流规则后，怎么验证分流是否真的生效了？
**答**：可以在浏览器中执行两个简单的交叉测试：
1. 访问国内 IP 查询站点（如 `https://ip138.com`），网页中显示的出口 IP 必须是您本地真实的大陆电信/移动 IP（表明国内流量完全直连）；
2. 打开海外短剧播放页面，视频能够顺畅秒开，且控制台网络瀑布流显示来自香港或新加坡节点（表明专线规则已精准命中生效）。

### Q2: 如果我偶尔还要看 YouTube 或使用 ChatGPT，规则会冲突吗？
**答**：完全不冲突。光速云提供的标准订阅配置中，已经预先内置了针对 Google、YouTube、OpenAI 等全球主流科技服务的规则集。这些服务会自动匹配对应的代理规则走专线，与黄果短剧的分流互不干扰、完美共存。

### Q3: 为什么有的视频海报刷得很快，但视频本身卡住？
**答**：这属于典型的“静态域名走专线、而动态媒体切片被误判直连”的分流漏洞。在极少数特殊自建流媒体源中，媒体分片的 CDN 域名可能使用了非标二级域名。如果在规则中补充了 `DOMAIN-SUFFIX,m3u8,PROXY` 与 `DOMAIN-SUFFIX,ts,PROXY` 后，客户端会直接根据文件的 MIME 后缀强制捕获并派发给专线，彻底消除遗漏。

### Q4: 轻量版每月 120GB 流量，在规则分流下够看多久？
**答**：在开启智能分流的前提下，120GB 流量完全不需要分摊给微信、淘宝等应用，100% 倾注于短剧播放。按 1080P 超清切片每集 55MB 测算，120GB 足够让您畅快刷完 **2,200 多集短剧（相当于近 30 部长篇完整连续剧）**！哪怕每天高强度刷上 70 集，也完全用不完。
