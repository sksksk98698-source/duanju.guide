## 02. 四大高频典型故障深度拆解与标准化解决方案 (SOP)

请对照您当前遇到的具体异常表象，执行对应的标准化排错：

### 故障一：节点测速全部超时标红（全部显示“Timeout / 无法连接”）
- **核心机理剖析**：
  - 光速云全线采用先进的 **VLESS 与 TLS 1.3 加密协议**。现代密码学为了防范恶意重放攻击（Replay Attack），要求客户端发起握手时携带的 Unix 时间戳与专线服务端之间的时间误差**不能超过 90 秒**；
  - 一旦您的电脑主板电池没电、手机手动调过时间、或者未开启网络自动同步，专线网关在核对时间戳时会断定连接非法，直接静默丢弃所有数据包，在客户端中瞬间呈现全盘飘红超时的假象；
- **标准化自救步骤**：
  1. **Windows 电脑**：进入系统【设置】->【时间和语言】->【日期和时间】，确保开启“自动设置时间”，点击下方的 **“立即同步”** 按钮；
  2. **Mac 电脑**：在终端运行强制授时命令：`sudo sntp -sS time.apple.com`；
  3. **手机（iOS / 安卓）**：进入【设置】->【系统/通用】->【日期与时间】，务必开启 **“自动设置”**；
  4. 同步完成后，彻底退出客户端重新打开，再次点击测速，节点瞬间全绿恢复！

### 故障二：订阅链接更新提示“404 Not Found”或“Profile Parse Error”
- **核心机理剖析**：
  - 为了防范外部恶意爬虫的批量撞库与网络嗅探，光速云的云端订阅分发网关会定期对订阅 API 接口进行动态安全轮转与防盗加固；
  - 如果您使用的是数个月之前的旧版静态订阅 URL，客户端可能会返回解析失败；
- **标准化自救步骤**：
  1. 打开浏览器登录 [光速云官方网站（guangsucloud.com）](https://guangsucloud.com)；
  2. 进入控制台仪表盘，找到“一键订阅”区域；
  3. 点击 **“复制 Clash 订阅链接”** 或 **“复制通用订阅链接”**（系统自动下发带最新鉴权签名的 API 地址）；
  4. 回到客户端中，新建一个配置并粘贴保存，旧配置直接删除即可完美解决。

### 故障三：开启代理后微信收不到消息、国内淘宝无法加载
- **核心机理剖析**：
  - 用户在客户端中误将运行模式设置为了 **“全局代理（Global / Proxy）”**，导致所有国内应用的流量被强行路由至海外专线，遭遇国内平台的异地风控阻断；
- **标准化自救步骤**：
  - 在 Clash Verge、Shadowrocket 等软件主界面中，立即将模式切回 **“规则模式（Rule）”** 或 **“配置模式（Config）”**，国内应用立即恢复本地极速直连。

### 故障四：当月专线套餐流量提前耗尽断流
- **核心机理剖析**：
  - 光速云的专线流量按自然月或账单周期每月全自动重置刷新；若追看短剧频率极高导致配额提前归零，专线会自动熔断保护，防止产生高额账单；
- **标准化自救步骤**：
  1. 登录光速云官网后台，查看仪表盘中的流量进度条；
  2. 若已达 100%，可在控制台点击 **“购买流量叠加包”**（低价补充临时高速专线流量）；
  3. 或者点击 **“升级套餐”**，补差价将轻量版（120GB/月）平滑升级至极速版（500GB/月），立即满血复活。

## 03. 电脑端高频端口冲突精准排查指令

在 Windows 或 Mac 电脑上，若启动客户端时弹出 `bind: address already in use` 报错，说明 `7890` 端口被其他软件霸占：

```powershell
# Windows PowerShell 管理员窗口排查占用 7890 端口的程序进程
Get-NetTCPConnection -LocalPort 7890 | Select-Object -Property OwningProcess, State

# 随后通过进程 PID 查询对应软件名称：
Get-Process -Id <OwningProcess-ID>

# 终极极简解法：
# 无需大费周章杀进程，直接在客户端设置中：
# 将“混合端口 (Mixed Port)”从 7890 手动修改为 17890 或 27890 并保存即可！
```

## 06. 常见售后 FAQ 问答库

### Q1: 节点测速变绿了，为什么打开黄果短剧依然提示打不开？
**答**：请检查浏览器的 Cookie 与 LocalStorage 缓存。如果之前在直连公网环境下访问过该网站，浏览器本地可能残留了带风控标记的污点会话。请按 `F12` 打开开发者工具，在 Application 中彻底清空当前网站的 Cookie 与缓存数据，随后按下快捷键 `Ctrl + Shift + R` 强制刷新即可顺畅秒开。

### Q2: 电脑重启之后，光速云客户端需要重新配置吗？
**答**：完全不需要。只要您在首次配置时勾选了“设为当前激活配置”，客户端会自动保存所有节点与分流策略。您可以在设置中勾选“开机自启（Launch at Login）”与“静默启动至托盘”，每次开机电脑会自动无感接管网络，开机即可秒开追剧。

### Q3: 为什么有的时候香港节点延迟会轻微浮动？
**答**：海底光缆在日常运营中偶尔会经历由国际海缆组织（如 APG、SJC2）主导的例行夜间维护或路由切换。光速云专网系统部署了全自动容灾探测机制，一旦某条光纤发生维护，流量会在数十毫秒内平滑热切换至备用内网专线通道，用户通常无需手动干预。
