## 01. 故障核心表象与网络栈故障诊断

在日常使用电脑或手机观看黄果短剧时，很多用户在安装、调试或强制卸载某些旧版加速软件、网络调试工具后，经常会遭遇一种极其荒诞的“半身不遂式断网”：
- **“微信/QQ 能正常发消息，但浏览器所有网页都打不开”**：即时通讯软件正常在线，但无论 Chrome、Edge 还是 Safari，只要打开任何网址，均立刻报错 `ERR_PROXY_CONNECTION_FAILED` 或 `DNS_PROBE_FINISHED_NO_INTERNET`；
- **关闭加速软件后电脑瞬间断网**：只要开启着代理软件，网络尚可勉强使用；一旦退出或关闭软件，整台电脑所有网络连接瞬间归零，连百度也无法打开；
- **虚拟网卡（TUN / TAP）冲突死锁**：控制面板网络连接中出现大量名为“Wintun”、“TAP-Windows Adapter”的异常虚拟网卡，无法禁用也无法删除；
- **移动端无线网络受限**：手机 Wi-Fi 旁边显示感叹号，提示“已连接但无法访问互联网”，即便重启路由器也无法恢复。

```
[System Ingress Socket Request Pipeline]
+-------------------------------------------------------------+
| Application Process: Chrome / Edge / YellowFruit ShortPlay  |
+-------------------------------------------------------------+
                            │
       (Socket Connect: socket(AF_INET, SOCK_STREAM, 0))
                            │
                            ▼
+-------------------------------------------------------------+
| Windows Registry: Internet Settings                         |
| ProxyEnable = 0x00000001 (Forced Active)                   |
| ProxyServer = "127.0.0.1:7890"                              |
+-------------------------------------------------------------+
                            │
       (Forwarding to Loopback Port 7890: NO LISTENER!)
                            │
                            ▼
+-------------------------------------------------------------+
| OS Network Subsystem: Port Closed (WSAECONNREFUSED 10061)   |
| Immediate Chrome Error: ERR_PROXY_CONNECTION_FAILED         |
| Entire Web Traffic Blackholed                               |
+-------------------------------------------------------------+
```

许多用户以为这是“网卡硬件烧了”或“宽带欠费”，甚至大费周章地重新安装操作系统。实则这属于最典型的**操作系统底层 TCP/IP 传输协议栈、Winsock 套接字目录或系统代理注册表键值发生严重紊乱与死锁**。

## 02. 网络协议栈与虚拟网卡锁死底层机理剖析

现代操作系统为了实现复杂的网络路由和代理转发，在协议栈中构建了层层抽象。一旦某些劣质软件非正常闪退，就会留下致命的“配置僵尸”：

### 1. Windows 系统代理注册表残留（悬空代理死锁）
当您开启某个客户端的“系统代理（System Proxy）”功能时，客户端会通过 Windows API 向注册表写入全局代理配置：
- 注册表路径位于：`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Internet Settings`；
- 键值 `ProxyEnable` 被置为 `1`，且 `ProxyServer` 被指定为本地回环端口（如 `127.0.0.1:7890`）；
- 如果此时电脑突然意外关机、软件闪退或用户直接使用任务管理器强制杀进程，**客户端根本没有机会执行“注销系统代理”的清理逻辑**；
- 电脑重启后，操作系统依然坚定地将所有应用程序的 HTTP/HTTPS 出站流量死死定向至 `127.0.0.1:7890`。而由于该端口根本没有监听程序，所有网络请求瞬间撞墙，造成“全网瘫痪”。

### 2. Winsock 目录服务提供者（LSP）链条被破坏
Windows 套接字 API（Winsock）支持分层服务提供者（Layered Service Provider - LSP）机制：
- 某些老旧的安全工具、游戏加速器或流氓防护软件，会将自己的 DLL 动态库强制挂载到 Winsock 协议栈的最底层，用于深度拦截所有进出网络包；
- 当这些软件被暴力删除或文件损坏后，注册表中的 LSP 链条出现断层；
- 操作系统在尝试创建基础 Socket 套接字时，因找不到对应 DLL 文件直接返回致命错误代码（如 `WSAEPROVIDERFAILEDINIT - 10106`），导致整台电脑的网络通信能力彻底丧失。

### 3. TUN 虚拟网卡与系统默认路由表（0.0.0.0/0）抢占
当使用高级 TUN（虚拟网卡）模式时，客户端会在系统中注册一块虚拟网卡，并通过 `route add` 指令将系统的全局默认网关（`0.0.0.0/0`）修改为该虚拟网卡的 IP 地址：
- 若虚拟网卡驱动未正常卸载，系统的底层路由表会将所有流量丢向一个已经不存在的虚拟设备（路由黑洞）；
- 表现为物理网卡灯在闪烁、IP 地址分配正常，但实际上任何数据包都无法发往真正的路由器网关。

## 03. 全平台网络栈深度重置与死锁清理标准作业程序 (SOP)

面对网络瘫痪，无需重装系统，请按照以下标准化流程进行彻底的底层重置与清理：

### 步骤一：Windows 电脑管理员“经典重置五连指令”

这是解决 Windows 绝大部分网络协议栈锁死的最权威、官方原生修复方案：

```cmd
:: 1. 在键盘上同时按下快捷键【Win + X】，在弹出菜单中选择【终端管理员】或【命令提示符 (管理员)】；
:: 2. 依次复制并粘贴执行以下 5 条系统级重置命令（每输一条按一次回车）：

netsh winsock reset
netsh int ip reset
route -f
ipconfig /release
ipconfig /renew
ipconfig /flushdns

:: 3. 命令原理解析：
:: - netsh winsock reset: 彻底还原 Winsock 目录与套接字提供者至出厂状态；
:: - netsh int ip reset: 重写 TCP/IP 堆栈底层注册表分支，消除静态死锁；
:: - route -f: 清理所有被第三方虚拟网卡篡改的非默认静态路由表项；
:: - ipconfig /flushdns: 清空本地受污染的 DNS 解析缓存。

:: 4. 关键动作：全部执行完成后，系统会提示“必须重新启动计算机才能完成重置”，请务必立即重启电脑！
```

### 步骤二：排查并彻底清除 Windows 悬空代理设置

重启进入系统后，检查系统级代理是否被彻底释放：
1. 按下快捷键 `Win + I` 打开系统设置；
2. 依次点击 **“网络和 Internet” -> “代理”**；
3. 检查右侧的设置项：
   - **“自动检测设置”**：保持开启；
   - **“使用安装程序脚本”**：必须关闭；
   - **“手动设置代理（使用代理服务器）”**：**必须确保处于【关闭】状态**；
4. 若此开关被锁死无法关闭，可直接在 PowerShell 管理员窗口执行注册表一键抹除命令：
   ```powershell
   Set-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings" -Name ProxyEnable -Value 0
   ```

### 步骤三：苹果 Mac 电脑重置网络位置与 DNS 缓存

针对使用 macOS 的 MacBook 或 iMac 用户：
1. 打开“终端（Terminal）”，执行 DNS 缓存刷新命令：
   ```bash
   sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
   ```
2. 进入“系统设置 -> 网络”：
   - 点击右下角的三点图标 `(...)`，选择 **“网络位置 -> 编辑位置”**；
   - 点击加号 `(+)` 新建一个名为“全新自动”的位置，点击完成并应用；
   - 系统会自动为所有物理网卡重建纯净的路由表与协议栈。

### 步骤四：手机端（iOS / Android）一键还原网络设置

针对手机无法上网或网络受阻：
- **苹果 iPhone 用户**：
  1. 进入【设置】->【通用】->【传输或还原 iPhone】；
  2. 点击【还原】-> 选择【还原网络设置】；
  3. 输入手机锁屏密码，等待手机自动重启（*此操作仅清空已保存的 Wi-Fi 密码与蓝牙，绝对不删除照片与应用*）；
- **安卓手机用户**：
  1. 进入【设置】->【系统和更新】->【重置选项】；
  2. 点击【重置 WLAN、移动数据网络和蓝牙设置】；
  3. 确认重置后重新连接家庭 Wi-Fi 即可。

| **微信能用，网页全挂** | 系统代理开关悬空残留 | `ERR_PROXY_CONNECTION_FAILED` | 关闭系统代理开关 + 清空注册表 ProxyEnable |

## 06. 常见高频技术 FAQ 问答库

### Q1: 执行 `netsh winsock reset` 后，电脑里的文件和软件会受影响吗？
**答**：绝对不会。`netsh winsock reset` 仅仅是 Windows 操作系统自带的一个网络诊断重置工具，它的作用仅仅是将系统注册表中关于“网络套接字通信接口（Winsock）”的配置还原为微软出厂默认状态，它绝对不会删除您的任何个人文件、桌面图标、软件或者浏览记录，完全安全可信。

### Q2: 手机执行“还原网络设置”后，需要重新输入 Wi-Fi 密码吗？
**答**：是的。手机还原网络设置会清除手机系统内部已保存的所有 Wi-Fi 连接记录、配对过的蓝牙设备列表以及由系统建立的 VPN 描述文件缓存。在重启手机后，您只需重新点击自家的 Wi-Fi 并输入密码即可重新联网，手机中的照片、聊天记录与应用程序完好无损。

### Q3: 为什么重置网络后，短剧网站依然提示“无法访问此网站”？
**答**：重置网络解决的是“本地操作系统的网络管道畅通”，确保了您的电脑能正常访问国内门户网站。而黄果短剧等海外平台的服务器架设在境外，直连访问依然会受到跨国公网丢包与地理版权围栏的拦截。在完成本地网络重置后，必须启动光速云专线客户端，才能顺畅解锁短剧视听。

### Q4: 怎么防止以后再出现“退出软件就断网”的问题？
**答**：牢记两条核心原则：
1. 彻底卸载所有来历不明的“一键翻墙加速器”或破解版辅助补丁；
2. 规范使用现代开源的客户端（如 Clash Verge Rev），在关闭软件时，请务必先在托盘图标上点击**“系统代理（System Proxy）”将其切换为关闭**，然后再右键点击“Quit（退出）”，切勿直接在任务管理器中强制结束进程。
